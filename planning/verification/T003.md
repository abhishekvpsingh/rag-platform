# T003 — Offline evaluation baseline verification

## Scope and acceptance

Implemented executable strict evaluation schemas, 45 invented evidence documents,
17 versioned cases (5 tuning / 12 held out), a synthetic CSV dataset, an offline
reference retriever, and an independent citation/access scorer. Explicit expected
revisions/locators, forbidden evidence, current/historical/future dates, conflicting
and partially superseded policies, regions, tenant/reader/owner grants, stale/
unknown/revoked permissions, deletions, corrupt-input metadata, multilingual text,
long text, exact identifiers, injection text, and numerical answers are encoded.

[Decision 0001](../decisions/0001-offline-evaluation-baseline.md) records library
compatibility, versioning, alternatives, targets and scope. No dependencies or
lockfiles changed. Owner software-license selection remains pending before release.

## Limits

Targets were fixed before the first baseline run. This small fixture set is public
and is not a blind external benchmark. Keep held-out questions out of tuning and
version future changes. The synthetic grant/date oracle is not production source
authorization or full policy resolution. Expected answer behaviors are encoded;
answer generation, SQL execution, and injection defense are not evaluated yet.
The reference baseline is not an implemented RAG product or capacity validation.
