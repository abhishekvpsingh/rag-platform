## Security behavior exercised

Concurrent and repeated bootstrap cannot create a second owner/tenant; tenant
foreign keys reject mismatched owners; same-tenant admins and other-tenant users
cannot read another owner's credentials or authorize their source. Missing/stale
source mappings, disabled connections, disabled accounts and revoked memberships
fail closed. Sessions expire/revoke; CSRF and exact Origin protect mutation;
secure cookie flags and no-store responses are asserted. Credential envelopes
reject cross-tenant/connection replay and tampering; rotation decrypts with the
new key. Validation/configuration messages and secret object representations omit
submitted secrets.

## Limits

See [runtime identity guidance](../../rag-platform/infra/IDENTITY.md). HTTPS is
operator configured; no login UI, OAuth connector, shared ACL/group engine, RLS,
shared rate limiter or production recovery drill is claimed. Source proof is a
trusted adapter boundary awaiting real providers. Rotation has a tested primitive,
not a bulk administrative command. All cloud services remain unprovisioned.
