# T007 verification — parser and indexing pipeline

## Implemented scope

TXT, Markdown, HTML text, text PDF, DOCX and value-only CSV/XLSX parsing; tenant-scoped
immutable artifacts; source identities/revisions/provider-version observations;
deterministic bounded passages with locators/offsets; explicit compatible embedding
adapter and fixture-only vectors; model-specific OpenSearch staging and atomic
PostgreSQL generation activation; installed ingestion worker handler/queue and
operator CLI. See [runtime limits](../../rag-platform/infra/INGESTION.md).

## Security and limits

The parser child uses a scrubbed environment, closed inherited descriptors,
Linux libseccomp default-deny syscall policy, CPU/memory/output limits and parent
wall timeout. Tests exercise denied network socket, filesystem read and fork.
No native macOS fallback is allowed; Linux Docker is the runtime there.

Parser fixtures contain generated public synthetic leave-policy text. Fixture
vectors are not semantic embeddings; these results do not establish retrieval
quality or real-provider compatibility. Provider failures use HTTP transport
fixtures. Real source account integration is T008/T009, retrieval T011, OCR T016.

OpenSearch staging may leave inactive records after interrupted/obsolete work;
future retrieval must enforce PostgreSQL active generations and current source
authorization. Raw index presence is not permission to retrieve content.
Full document backup/restore and physical retention/purge remain future work.
Migration 0003 was adjusted only before merge/deployment; previous migrations
were not edited.
