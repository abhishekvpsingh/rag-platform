# T005 web shell verification

Local acceptance on the T005 working tree (2026-11-14), based on merged T004

## Behavior

The responsive shell exposes Overview, Ask, Sources, Knowledge, Quality,
Operations and Settings as real routes. Navigation includes current-page
semantics, a skip link and visible keyboard focus. Unknown routes offer a real
return link. Shared state presentation includes empty/loading/partial/stale/
forbidden/failed/retrying/success; Next boundaries announce loading/failure and
invoke the actual route reset on retry. Unimplemented controls are absent.

## Limits

These are honest availability screens, not a mock connected workspace. No source
metadata, model calls, live metrics, settings mutation or authentication UI is
wired. No full WCAG conformance audit is claimed. Authenticated data flows and
related loading/stale/forbidden transitions need verification when their APIs
are implemented. Public shell routes expose no private data.
